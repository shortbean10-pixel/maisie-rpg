Maisie Potter RPG — Build 0.8

This is a real static website/PWA build, not a single preview file.

To use every feature:
- Publish the entire folder to an HTTPS web host.
- Open the published URL in Safari on iPhone.
- Camera permission will then work.
- You can use Safari > Share > Add to Home Screen.

Included:
- working navigation
- messages with unread badges, chat threads, typing indicators and replies
- family group chat
- contacts linking to messages
- camera with front/back switching
- camera photos saved using IndexedDB
- Photos app
- notes autosave
- inventory actions
- tasks
- relationships
- outfits
- time progression
- notifications
- local save data
- installable PWA/service worker

Build 0.8:
- Separate Story view opens by default; Hub keeps the phone, bag and free-time tools.
- Playable packing-night chapter with branching dialogue.
- Three untimed optional mini games: packing, owl care and matching pairs.
- Chapter progress saves on this device, with replay and one-time hub rewards.
- Existing v0.7 hub saves are preserved.
